CLAUDEMON

Claudemon turns your Claude Code agents into a crew of pixel creatures you can watch work. Point one at a folder, tell it what to build, and it gets to work in your files while you follow along from its tank. Each creature is a real agent with its own personality and working style. When you want a break, one click drops you into Clawland, a brawler where a tiny creature eats its way across an island.

what it actually is

Agents you can see

Claudemon is a Claude Code plugin. Your creatures are the agents: give one a folder and a task and it does real work in your files, while you watch it potter around its tank instead of reading a wall of text.

📁

Give it a job

Point a creature at a folder, type what you want built, and it goes and builds it. You check your files afterward, not a chat log.

👥

A crew, not one bot

Every creature is its own agent with a personality and a working style. Collect a roster and send whoever fits the job.

💬

It talks while it works

Claude voices your creature in character as it goes, so you can tell what it's up to at a glance. Mute it any time in settings.

…and it's secretly a whole game

🌍 CLAWLAND

A single-player brawler, one click from the app. You spawn as a hatchling and eat to grow. Stand on a node to claim it and start a clan, then push your territory outward while rival clans and the Corrupted push back. It doesn't really end; you just try to get bigger before something eats you.

start small — a Lv 3 hatchling foraging the jungle
grow & spread — leveling up and taking territory
WASD  move
L-click  attack
R-click  special
Space  dash
U  ultra
M / C  map / stats

Per-creature progression persists across runs. Procedural attack VFX and synthesized sound, no audio files.

quick start

Get it running

Claudemon plugs into Claude Code, so that's the one thing you need. Setup is a single command — no paths to edit, no Docker, no account, no config files to touch. Plain Node (≥ 24) on Windows, macOS, or Linux.

1

Grab the code

git clone https://github.com/OriginalName457/claudemon
cd claudemon
2

Run one setup command

It finds the path for you, installs the Claude CLI if you don't have it, and registers Claudemon. Nothing to edit by hand.

npm run setup
3

Restart Claude Code

Say “show Clawde” and your tank opens at localhost:4573. That's the whole thing.

Want the pixel pet in your terminal statusline too? npm run setup -- --statusline · just poking around? npm run app opens the tank without Claude.
